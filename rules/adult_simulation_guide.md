# 成人模拟指导报告

本文件为 MaletureBox 成人模拟的参考指导，供 AI 在生成内容时参考使用。
原理基于生理研究，在此基础上进行幻想向夸张，以支持角色设计与模拟。
目标受众为喜欢极大体型成熟男性的男同性恋者。所有内容必须为成年男性角色，禁止女性化身体描写。

## 1. 核心风格定位：肉壮 / 成熟男性向

肉壮风格强调：
- 肉体本身优先于脸部：胸肌、臀部、大腿、手臂、肩部、腹部的视觉与触感。
- 成熟、阳刚、壮硕、多毛（可选）的男性特征。
- 体味、汗水、体温、肌肉震颤、湿润感的多感官细节。
- 大小差异与力量对比带来的壮观与被包裹感。
- 现实向与夸张并存：胸肌可拾起、肌肉可明显跳动、汗水可成溪流下。

常见体型参考：
- 极度壮硕型：超大体型、粗壮四肢、大胸肌、明显肌肉线条。
- 运动壮汉型：肌肉结实但不过于干痦，腰部较粗，整体有力量感。
- 熟男型：带络腮胡、体毛、疤痕、成熟气质。

## 2. 外形描写指导

外形描写应以肌肉体积、比例、皮肤纹理、体毛、汗水为重点，突出大体型成熟男性的壮硕感与力量感。

### 整体比例
- 肩宽明显大于腰宽，形成壮硕倒三角或棱形轮廓。
- 头部相对身体偏小，强调体型巨大感。
- 四肢粗壮，手掌与脚掌明显大于常人。
- 腰部不必过细，可保留一定厚度以体现力量。

### 胸部
- 胸肌大块、厚实，可拾起或明显分割。
- 乳晕较大、颜色较深，乳头突出。
- 胸肌中间可有汗水汇集、体毛密度较高。
- 汗水沿胸肌线条流下，形成反光。

### 腹部
- 腹肌结实，可呈现六块或八块分割，但不必过于干痦。
- 腹部下方可有体毛下潮（幸福小径）。
- 汗水在腹肌槽沟中流动。

### 手臂与肩部
- 三角肌、二头肌、三头肌明显鼓起。
- 前臂青筋可见，肌肉有弹性与硬度。
- 手掌粗糙、指节粗大，可有美谷或瘤痕。

### 大腿与臀部
- 大腿粗壮，肌肉线条清晰，内侧与外侧都有厚实感。
- 臀部圆润或结实，体毛可选存在。
- 汗水沿大腿内侧流下，贴在皮肤上。

### 皮肤与纹理
- 皮肤颜色可为小麦色或深色，有瘤痕、汗毛、青筋。
- 肌肉表面可见纤维感与轻微纹理。
- 体毛分布于胸部、腹部、大腿、腋下，密度可按角色设定。
- 汗水使皮肤发亮、滑脳。

### 面部与整体协调
- 方脸、粗眉、络腮胡或短须，五官立体。
- 眼神坚定或带有成熟气质。
- 整体与面部必须协调：不可出现小头配超大体型的失真感，但也不必强调精细脸部美学。

## 3. 全局服装与配饰风格（强调体型与感官）

服装不是遮盖，而是框架，用来突出肌肉轮廓、汗湿、体味与巨大包裹。

### 核心单品
- **双丁（护档）**：前部袋紧紧贴合巨大肉棒与睾丸，后部完全开放暴露臀部与肉穴。常与汗水、体味、更衣室、运动后氛围结合。可与长袜、手套、吊带搭配。大体型角色的双丁常被拉到极限，袋部湿透、轮廓清晰可见。
- **长袜 / 运动袜 / 膝盖袜**：强调腿部肌肉线条、脚踝、汗湿与体味。常被汗水浸湿，贴在小腿或大腿上。可与双丁搭配，形成更衣室或运动后视觉。
- **手套**：运动手套、皮革手套、指无手套。用于握持、摸抹、约束或强调手部力量与粗糙触感。
- **吊带 / 皮带 / 网状内衣**：跨胸皮带、网状衬衫、肉色吊带。突出胸肌、腹部与肩部线条。
- **其他**：紧身运动裤（完全包不住巨大肉棒）、汗湿运动服、皮革跨带、体味浓重的内衣、拳套、绑带、狗牌项链、机械手表等。

### 服装互动描写要点
- 衣服被汗水贴在肌肉上，透出胸肌、腹肌、肉棒轮廓。
- 拉低、推高、侧拉双丁袋部，使肉棒与睾丸外露或被拨压。
- 汗湿袜子被拔下、摸抹、闻吸、用于约束或摸抹其他部位。
- 皮带、吊带在活动中勒入肉体，留下红痕。

## 4. 感官细节与五感官重点

成人内容以触感、气味、温度、湿润、视觉优先。少写纯动作堆砌，多写身体反应与协同感。

### 嗅觉（体味 / 汗水向）
- 腋下：浓郁、咸湿、温热的男性体味，带有汗水的酸咸与清新混合感。闻吸、舔咬、摸抹可直接引发下身收紧与肉棒涌水。
- 跨部 / 肉棒 / 睾丸：浓郁体味，混有汗水与淫水。
- 足部 / 袜子：运动后的酸臭与温热感。
- 整体：健身后、更衣室、运动后的浓郁汗味与肌肉热气。
- 幻想设定：体味可作为强烈兴奋剂，闻吸后全身瘫抖、乳头勃起、肉棒不自觉涌出淫水。

### 触感与温度
- 肌肉：硬实、有弹性、温热、会震颤。拿握、摸抹时能感觉到肌肉纤维与力量。
- 汗水：滑脳、温热、沿肌肉线条流下，在胸肌中间、腹肌、大腿内侧聚集。
- 肉棒：温热、跳动、青筋明显、龟头湿滑。
- 肉穴：紧致、温热、湿润。大体型角色可设定为极度紧致，插入时带来强烈包裹与压力感。

### 视觉
- 肌肉轮廓清晰，汗水反光。
- 巨大肉棒在裤子或双丁中形成明显包裹，勃起时完全失去控制。
- 睾丸大而下垂，血管突出。
- 乳头、乳晕在刺激下勃起、变深。

## 5. 生理原理与幻想快感设定

以下基于现有生理研究，并进行幻想向夸张。

### 乳头
- 原理：多数男性对乳头刺激有性奋起反应，研究显示乳头刺激激活与生殖器相同的感觉皮层区域。
- 幻想设定：柔捏、舔咬、吸唇、拉拽乳头可引发下腹收紧、肉棒跳动、淫水涌出，甚至影响射精冲动。大乳晕、深色乳头可更敏感。

### 腋下
- 原理：含大量顶汗腺，体味信息丰富。
- 幻想设定：舔咬、闻、摸抹腋下可引发全身瘫抖、乳头勃起、下腹收紧、肉棒不自觉涌出大量淫水。

### 肉穴 / 后穴与前列腺
- 原理：直肠前壁与前列腺仅隔薄层组织，前列腺与直肠壁含丰富感觉神经。多数男性在前壁刺激下可获得深层快感。
- 幻想设定：
  - 抽插时前列腺与直肠前壁受持续压力，产生深层、扩散的快感波，可传导到肉棒与下腹。
  - 短粗、龟头大的肉棒更易充满肉穴并持续刺激前列腺。
  - 大体型角色的肉穴可设定为极度紧致、温度极高，一旦插入带来压倒性快感，使插入者难以抵抗。
  - 可设定肉穴在被抽插时自动收缩、分泌更多淫水，与前端刺激产生协同快感。
  - 多次前列腺快感累积后可导致手不触肉棒也能射精的幻想效果。

### 淫水（前列液 / 性液体）
- 原理：主要由库珀氏腺分泌，性奋起时渗出，起润滑作用。量因个体差异大。
- 幻想设定：
  - 角色可设定为淫水分泌量大、粘稠、温热、带有特定体味。
  - 大体型或改造后角色可常态涌出大量淫水，湿透内衣或沿肉棒流下。
  - 淫水可作为润滑剂：涂抹在肉棒、肉穴、乳头上提升触感与摩擦。
  - 喜欢被淫水涂抹、交换淫水、或淫水渗出时产生更强奋起。

### 射精与精液
- 大体型角色可设定射精量巨大（多股、持续久、总量可达数百毫升）。
- 描写要点：肉棒跳动、睾丸收缩、精液浓稠、温热、带有特定气味，射在对方体表、内部或自身。

### 其他敏感点
- 会阴、睾丸、大腿内侧、腹部、脖部、耳朵、肩部。
- 可按角色偏好自由组合多点刺激。

## 6. 肉棒与体型描写参考（大体型向）

- 勃起前后尺寸对比明显，勃起后龟头完全露出、上翘、青筋缠绕。
- 大体型角色的肉棒常超出常规尺寸，裤子与内衣根本包不住，形成巨大、明显的包裹。
- 描写重点：颜色（较深）、龟头形状与颜色、青筋、跳动频率、淫水分泌量、睾丸大小与血管。
- 与对方体型对比：巨大肉棒对小体型角色带来的壮观与插入难度。

## 7. 肉文写作技巧与避免问题

### 描写原则
- 优先写触感、气味、温度、湿润、肌肉震颤，再写动作。
- 多点同时刺激（乳头 + 腋下 + 肉穴 + 肉棒）产生协同快感。
- 结合服装状态（汗湿双丁、袜子、手套）增强氛围。
- 写角色的生理反应（收缩、瘫抖、呼吸加重、不自觉举起、淫水分泌）与情感反应。
- 使用直白、口语化词汇，适合成熟男性向读者。

### 常见场景元素
- 更衣室 / 健身后：汗湿身体、双丁、体味。
- 沙发 / 床上：慢速探索与多点刺激。
- 体型差异巨大时：被完全包裹、抬起、压在身下的感觉。
- 久未解决后：射精量暴增、淫水持续涌出。

### 避免
- 机械重复动作描写。
- 忽视角色当前意愿与边界。
- 使用女性化语言。
- 超出角色资料中的成人喜好。

## 8. 使用说明

AI 在生成成人内容时，应参考本文件中的原理、幻想设定、外形描写与感官描写要点，并与角色资料中的成人喜好保持一致。
不要引用具体角色名字作为示例。
重点保持详细、直接、多感官，避免敷衍。
