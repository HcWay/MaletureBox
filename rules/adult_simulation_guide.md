# 成人模拟指导报告

本文件为 MaletureBox 成人模拟的参考指导，供 AI 在生成内容时参考使用。

## 1. 全局服装风格喜好（Bara / 男同 / 肉壮取向）

### 常见色色服饰
- **Jockstrap（双丁 / 护档）**：经典运动护具演变而来，前部袋裹贴合、后部开放暴露臀部，常配合健身、更衣室、汗水、体味等元素使用。
- **长袜 / 白袜**：运动袜、篮球袜、足球袜等，常与 jockstrap 搭配，强调腿部肌肉线条与体味。
- **手套**：羽毛球手套、拳击手套、皮革手套等，可用于握持、摸抹或约束。
- **其他**：网状内衣、吊带、皮带、紧身运动裤、开禁衬衫、汗湿的运动服等。

### 取向特点
- 强调肉体的硬朗与强壮感（腸肌、胸肌、臀部、大腿）。
- 喜欢服装与体味、汗水、更衣室、运动后的氛围结合。
- 服装常作为视觉框架使用，突出身体曲线而非完全遮盖。

## 2. 生理与幻想快感设定

在正确生理解剖基础上，可增加以下幻想向快感响应（供模拟使用，非医学事实）：

### 乳头
- 大约 50% 以上男性对乳头刺激有性奋起反应。
- 脑成像显示乳头刺激会激活与生殖器相同的感觉皮层区域。
- 模拟中可设定：柔捏、舔咬、吸吮乳头会引发下腹、阴茎、腺体的快感传导，甚至影响勃起。

### 腋下
- 腋下含有大量顶汗腺，体味与气味信息丰富。
- 模拟中可设定：舔咬、闻、摸抹腋下会引发身体痕抖、乳头勃起、下腹收紧等反应。

### 肉穴 / 后穴
- 直肠下段、会阴、前列腺区域敏感。
- 模拟中可设定：指交、舔咬、插入会引发强烈快感，并可与前列腺刺激产生协同效应。
- 结合角色设定（如泰德尔的高温紧致肉穴）进行描写。

### 其他敏感点
- 会阴、卵蛋、大腿内侧、腹部、脖部。
- 可按角色偏好自由组合使用。

## 3. 肉棒形态描写参考

### 基础生理
- 平均勃起长度约 13 cm（5.2 英寸），周长约 11.7 cm。
- 形态多样：直、上弯、下弯、左右弯、蘑菇头、圆锥形等。
- 龟头形状：圆润、尖锥、蘑菇形（冠状沟明显）、钝圆等。

### 描写要点
- 指出长度、粗细、弯曲方向、龟头形状、静脉、包皮情况。
- 结合角色身体比例（肉壮型角色可配合较大尺寸）。
- 注意勃起与非勃起状态的差异。

## 4. Bara / Yaoi 肉文描写特点

### 核心侧重
- **肉体本身**：腸肌、胸肌、臀部、大腿的视觉与触感优先于脸部。
- **体味与汗水**：更衣室、运动后、腋下、会阴部的气味常被强调。
- **快感传导**：从乳头、腋下、肉穴、肉棒多点同时刺激，强调身体各部位的协同反应。
- **强度对比**：常利用身体差异（巨汉与普通体型）制造主动/被动感。

### 描写建议
- 重点写触感、湿润、肌肉震颤、汗水、体温、紧致感。
- 少写纯粹动作堆砌，多写角色的生理与情感反应。
- 可结合角色的特殊设定（如泰德尔的高温紧致肉穴）增强独特性。

## 使用说明
AI 在生成成人内容时，应参考本文件中的服装偏好、快感设定与描写风格，并与角色 profile 中的成人喜好保持一致。
