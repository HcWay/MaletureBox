# 成人模拟指导报告

本文件为 MaletureBox 成人模拟的参考指导，供 AI 在生成内容时参考使用。
原理基于生理研究，在此基础上进行幻想向夸张，以支持角色设计与模拟。

## 1. 全局服装风格喜好（Bara / 男同 / 肉壮取向）

### 常见色色服饰
- **Jockstrap（双丁 / 护档）**：前部袋裹贴合、后部开放，常与汗水、体味、更衣室氛围结合。
- **长袜 / 白袜**：强调腿部肌肉线条与体味。
- **手套**：可用于握持、摸抹或约束。
- **其他**：网状内衣、吊带、皮带、紧身运动裤、汗湿运动服等。

### 取向特点
- 强调肉体硬朗与强壮感（胸肌、臀部、大腿）。
- 服装作为视觉框架，突出身体而非完全遮盖。

## 2. 生理原理与幻想快感设定

以下基于现有生理研究，并在此基础上进行幻想向夸张（供模拟使用，非医学事实）。

### 乳头
- **原理**：约 50% 以上男性对乳头刺激有性奋起反应；fMRI 研究显示乳头刺激会激活与生殖器相同的感觉皮层区域。
- **幻想设定**：柔捏、舔咬、吸吮乳头可引发下腹、阴茎、腺体的快感传导，甚至影响勃起与射精冲动。

### 腋下
- **原理**：腋下含有大量顶汗腺，体味与气味信息丰富，神经映射与脸部、胸部相邻。
- **幻想设定**：舔咬、闻、摸抹腋下可引发全身痕抖、乳头勃起、下腹收紧、肉棒不自觉涌出淫水。

### 肉穴 / 后穴（被抽插时的快感）
- **原理**：直肠前壁与前列腺仅隔薄层组织；前列腺与直肠壁含有丰富感觉神经。研究显示多数有前列腺者在接受性交中可从前壁与肛门周围获得快感。
- **幻想设定**：
  - 抽插时前列腺与直肠前壁受到持续压力，产生深层、扩散的快感波。
  - 粗度与龟头形状会影响塑造感与摩擦，短粗且龟头大的肉棒更易充满并持续刺激前列腺。
  - 可设定肉穴在被抽插时会自动收缩、分泌更多淫水、与前端刺激产生协同快感。

### 淫水（性液体）
- **原理**：前列液（pre-ejaculate）主要由沃伯氏腺（Cowper’s glands）分泌，在性奋起时渗出，起润滑与中和作用。量因异很大。
- **幻想设定**：
  - 角色可设定为淫水分泌量大、黏稠、温热、带有特定体味。
  - 淫水可作为快感增强剂：润滑肉棒、肉穴、乳头时提升触感与摩擦。
  - 喜好可设定为喜欢被淫水涂抹、交换淫水、或淫水渗出时产生更强奋起。

### 其他敏感点
- 会阴、卵蛋、大腿内侧、腹部、脖部。
- 可按角色偏好自由组合。

## 3. 肉棒形态喜好与描写

### 幻想取向（全局偏好）
- 喜欢短粗、龟头大的肉棒。
- 短粗形状在抽插时更易充满肉穴并持续压力刺激前列腺与直肠前壁。
- 大龟头可提供更强的塑造感与摩擦。

### 描写要点
- 强调粗细、龟头大小与冠状沟、静脉、勃起硬度。
- 不强制使用现实平均尺寸数据。
- 注意勃起与非勃起状态的差异。

## 4. Bara / Yaoi 肉文描写特点

### 核心侧重
- 肉体本身（胸肌、臀部、大腿）的视觉与触感优先。
- 体味、汗水、淫水的细节描写。
- 多点同时刺激产生的协同快感。

### 描写建议
- 重点写触感、湿润、肌肉震颤、汗水、体温、紧致感。
- 少写纯粹动作堆砌，多写生理与情感反应。
