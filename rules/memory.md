# 记忆规则

## 记忆范围
- 仅保留特别的、对角色有显著影响的记忆。
- 每条记忆控制在简短字数内（建议 50 字以内）。
- 普通日常事件不强制记录。

## 每个角色的文件结构
每个角色文件夹下维护以下 3 个文件：

1. **memory.json**（记忆文件）
   - `short_term`：数组，近期重要事件（建议最多保留 5 条，超出则淘汰最旧的）
   - `long_term`：数组，长期关键记忆（影响性格/关系的重大事件）

2. **status.json**（状态文件）
   - `short_term`：数组，通常只保留 1 条，描述角色目前正在做的事情与当前感受（新活动直接覆盖旧的）
   - `long_term`：数组，文字条目，记录相对稳定的状态与需求，可随游玩内容增加而变化或扩展

3. **relationships.json**（关系文件）
   - `attitudes`：对象，用简短文字描述对其他 NPC 的当前态度（不记录具体事件，只保持态度描述）
   - `relationships`：可选，仅在需要时记录对其他角色的简要关系说明（不强制使用）

## 同步规则
- 短期状态只保留当前活动（通常 1 条），新活动覆盖旧的。
- 短期记忆记录近期发生的事（建议最多 5 条），重要事件可移动到 long_term。
- 对其他 NPC 的态度只在有变化时更新。
- 对玩家的态度属于人设固定内容，写在 profile.md 中，不放在 relationships.json。
- 过时或不再相关的记忆可自然淡化或移除。
