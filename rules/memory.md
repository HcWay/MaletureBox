# 记忆规则

## 记忆范围
- 仅保留特别的、对角色有显著影响的记忆。
- 每条记忆控制在简短字数内（建议 50 字以内）。
- 普通日常事件不强制记录。

## 每个角色的文件结构
每个角色文件夹下维护以下 3 个文件：

1. **memory.json**（记忆文件）
   - `short_term`：数组，近期重要事件（建议最多保留 10–15 条，超出则淘汰最旧的）
   - `long_term`：数组，长期关键记忆（影响性格/关系的重大事件）

2. **status.json**（状态文件）
   - `short_term`：当前情绪、位置、身体状态、最近活动等（每次互动后更新）
   - `long_term`：相对稳定的状态标记（如身体需求、习惯、慢性影响等）

3. **relationships.json**（关系文件）
   - `relationships`：对象，记录与具体对象（玩家/其他NPC）的关系变化事件
   - `attitudes`：对象，记录对其他角色的当前态度（随关键事件写入）

## 同步规则
- 短期内容只写入短期字段
- 长期内容只写入长期字段
- 关系与态度只在“改变关系的事件”发生时写入
- 过时或不再相关的记忆可自然淡化或移除
