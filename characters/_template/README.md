# 角色创建模板

当 AI 需要创建新角色时，必须先阅读本文件夹下的 `profile.md` 和 `state.json` 作为模板。

## 使用方法
1. 复制 `profile.md` 和 `state.json` 到新的角色文件夹（文件夹名使用小写英文名，用连字符分隔，如 `tydel-north`）。
2. 按照模板结构填写内容，不要删除已有的标题和字段。
3. 空白或“待补充”的部分可以留着，以后再填。
4. 创建完后，在仓库根目录的 `README.md` 角色列表中添加该角色。

## 注意
- `profile.md` 存放相对稳定的角色资料（性格、背景、偏好、边界等）。
- `state.json` 存放会随模拟变化的当前状态（心情、位置、近期记忆、关系数值等），每回合结束后应更新。
